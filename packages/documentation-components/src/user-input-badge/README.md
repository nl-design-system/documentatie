# User Input Badge

Een component om user input weer te geven, zoals een toetsaanslag, gamepad buttons, menu's die aangeklikt moeten worden, etcetera.

Op dit moment is er alleen een keyboard variant, en dat is de default variant. Op termijn moeten er meer varianten komen, en er moeten ook nog aanvullende componenten komen voor key-combinaties en key sequences.

## Achtergrond van het HTML-element `kbd`

> The `kbd` element represents user input (typically keyboard input, although it may also be used to represent other input, such as voice commands).

Bron: [The `kbd` element - HTML specification](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-kbd-element)
