Inloggen lukt zonder dat je iets uit je hoofd hoeft te weten, uit te rekenen of over te typen. Je wachtwoordmanager mag de velden vullen, je mag een code plakken, of je logt in op een manier die helemaal geen geheugenwerk vraagt.

Dit speelt bij elke stap waarin de bezoeker zich moet aanmelden: inloggen, een tweede factor bevestigen en een wachtwoord herstellen. Een test op een pagina die niets met inloggen te maken heeft, zoals een CAPTCHA onder een contactformulier, valt niet onder dit criterium. Daarover lees je meer bij [1.1.1 Niet-tekstuele content](/wcag/1.1.1/).
