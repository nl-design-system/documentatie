# Zet de foutmeldingen bij de betreffende formuliervelden

Voor foutmeldingen geldt hetzelfde als voor descriptions: de beste locatie is boven het formulierveld. Koppel de foutmelding met `aria-describedby` aan het formulierveld. Een screenreader leest de melding dan voor bij het veld. WCAG vraagt geen specifieke techniek; dit is een richtlijn van NL Design System.

Hoe dit te doen is beschreven bij de richtlijn [Plaats descriptions tussen label en formulierveld](/richtlijnen/formulieren/descriptions/plaatsing).
