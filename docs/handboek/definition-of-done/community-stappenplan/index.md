# Community stappenplan

Het Community stappenplan bestaat uit 2 fases. Elke fase wordt afgerond voordat de volgende fase kan beginnen.

## 1. Selectiefase

De community zorgt met de Selectiefase zorgen dat andere organisaties genoeg input hebben om de component succesvol te kunnen hergebruiken.

Alleen een component die voldoende is gedocumenteerd, wordt op de website, in de algemene Figma bibliotheek en andere hulpmiddelen van NL Design System beschikbaar gemaakt.

Meer weten? [Bekijk de stappen van de Selectiefase](./selectiefase.mdx)

## 2. Publicatiefase

Het kernteam zorgt met de Publicatiefase dat de component makkelijk kan worden gevonden op de website, kan worden doorontwikkeld door de community en kan worden ingezet in diverse huisstijlen.

De Community component is beschikbaar in the Themes repository, in Figma, op [nldesignsystem.nl](https://nldesignsystem.nl) en in alle prototypes en hulpmiddelen die het kernteam onderhoudt.

Meer weten? [Bekijk de stappen van de Publicatiefase](/handboek/estafettemodel/componenten/community/publicatiefase)

## Voortgang bekijken

Op de componentpagina's van componenten die ten minste de Help Wanted status hebben bereikt is de voortgang van het Community proces te volgen onder het kopje Definition of Done.

De stappen worden bijgehouden in de GitHub projectborden van verschillende organisaties in de community `Community Components - {organisatie}`. Voorbeelden van Community borden zijn:

- [Community Components - Utrecht](https://github.com/orgs/nl-design-system/projects/36)
- [Community Components - Amsterdam](https://github.com/orgs/nl-design-system/projects/48)
- [Community Components - Rijkshuisstijl Community](https://github.com/orgs/nl-design-system/projects/69)
- [Community Components - Den Haag](https://github.com/orgs/nl-design-system/projects/55)
- [Community Components - Rotterdam](https://github.com/orgs/nl-design-system/projects/107)
- [Community Components - Clippy](https://github.com/orgs/nl-design-system/projects/106)
- [Community Components - RVO](https://github.com/orgs/nl-design-system/projects/49)

:::info[Emojis]
Om goed overzicht te houden in het bord met veel kolommen gebruikt het kernteam emoji's in de titel van elke kolom om de fase waar een stap bij hoort aan te duiden. De volgende emoji's worden voor de verschillende fases gebruikt:

1. 🔍: Selectiefase. Vergrootglas wordt hier gebruikt omdat in deze fase gespeurd wordt of er voldoende community input beschikbaar is om aan de rest van het Hall of Fame proces te beginnen.
2. 🚀: Publicatiefase. Raket wordt hier gebruikt omdat de component in deze fase gelanceerd wordt.
   :::
