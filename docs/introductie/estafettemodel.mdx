# Open source samenwerken

<Paragraph appearance="lead">
  Het Estafettemodel is een door NL Design System ontwikkelde aanpak die samenwerken aan open source makkelijk maakt.
</Paragraph>

De community rondom NL Design System bestaat uit 900+ specialisten van verschillende overheidsorganisaties en hun leveranciers. Hiermee wordt toegewerkt naar een gezamelijk design system met ruimte voor innovatie en maatwerk.

Belangrijk hierbij is om niet steeds opnieuw te beginnen, maar elkaar ook niet vertragen bij de ontwikkeling van nieuwe applicaties. Daarom werken we met het Estafettemodel.
