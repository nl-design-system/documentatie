# Introductie

<Paragraph purpose="lead">
  Overheidsorganisaties bouwen allemaal websites en applicaties waarop mensen iets moeten kunnen regelen. Bij NL Design
  System maken zij de onderdelen daarvoor samen, zodat elke organisatie ze kan hergebruiken.
</Paragraph>

Overheidsorganisaties hebben allemaal dezelfde opgave: een website die mensen begrijpen, een menu dat ook met alleen een toetsenbord werkt, een pagina die voorleessoftware goed kan voorlezen en een formulier dat mensen zelfstandig kunnen invullen. Door die oplossingen te delen, hoeft niet elke organisatie hetzelfde werk opnieuw te doen. Elke organisatie houdt daarbij de eigen huisstijl en identiteit.

Gebruik deze introductie om te leren waaruit NL Design System bestaat, hoe organisaties er samen aan werken en hoe je er zelf gebruik van kan maken.
