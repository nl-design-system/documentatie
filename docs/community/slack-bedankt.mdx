# Bedankt voor je aanmelding voor Slack

Je ontvangt binnen enkele minuten een uitnodiging per e-mail voor de [Slack van Code for NL](https://codefornl.slack.com/). Niets ontvangen? Kijk ook in je map met ongewenste e-mail.

Zodra je bent aangemeld:

- Praat mee in het kanaal `#nl-design-system`. Stel hier je vragen of volg de gesprekken.
- Bekijk de [andere chatkanalen van NL Design System](/slack#chatkanalen).
- [Bekijk bijeenkomsten waar je aan mee kunt doen](/community/events/overzicht).
